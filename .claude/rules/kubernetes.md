# Kubernetes rules — Daidalos cluster

Applies to everything under `clusters/daidalos/`.

## Context

- Daidalos is a learning cluster (single node). Production stays on Docker
  Compose on Mnemosyne. Don't propose migrating stacks unless I ask.
- **Flux reconciles `clusters/daidalos/` from Gitea. A push there is a deploy.**
  The Compose webhook does not touch this directory.
- `clusters/daidalos/flux-system/` is generated by `flux bootstrap`
  (`gotk-components.yaml`, `gotk-sync.yaml`). Never edit it by hand.

## Secrets

- No plaintext `Secret` manifests in the repo — it is mirrored publicly.
- SOPS is planned, not implemented. Until then: reference secrets by name only
  and tell me which secret I have to create manually
  (`kubectl create secret ...` with key names, no values).

## Storage

- Longhorn is planned, **not installed**. Don't assume a `longhorn`
  StorageClass exists. Check `kubectl get storageclass` before writing a PVC.
- Once Longhorn is installed: single node means replica count 1. The default
  of 3 leaves every volume degraded.

## Commands

- Read-only is fine: `kubectl get/describe/logs`, `flux get ...`,
  `flux logs`, `flux tree ...`.
- Never run state-changing commands unless I ask in this session:
  `kubectl apply/delete/edit/patch/scale`, `helm install/upgrade/uninstall`,
  `flux bootstrap/uninstall/delete/suspend/resume/reconcile`.
  Changes reach the cluster only through my commit and Flux.

## Verification before proposing a commit

- Render: `kubectl kustomize <dir>` must succeed for every touched
  kustomization.
- Validate: `kubectl apply --dry-run=server -f <rendered>` (server-side catches
  unknown CRDs and admission errors). Dry-run only — ask first.
- Images: Daidalos is x86_64, so arm64 gaps don't apply here. Check that the
  image tag exists before writing it.
- Every name you reference (namespace, StorageClass, Secret, CRD version) must
  exist in the cluster or in the same commit. Look it up.

## After I pushed

Check the reconciliation read-only and report the actual output:
`flux get kustomizations`, `flux get helmreleases -A`, then
`kubectl get pods -n <ns>` and logs of anything not `Running`/`Ready`.
"Applied" is not "working".
